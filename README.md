# Student Registration App
   **Live demo:** https://sky5532.github.io/student-registration-app/
   
A React app for registering students and managing their courses.

## Features
- Add a student name and course
- Display all registered students
- Search students by name or course
- Delete a student

## Concepts used
Forms (controlled inputs), `useState`, arrays, `.map()`, `.filter()`

## Tech
React, Vite, CSS

## Run locally
1. Clone the repo
2. `npm install`
3. `npm run dev`
4. Open the local URL shown in the terminal
